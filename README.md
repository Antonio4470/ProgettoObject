# Gestore ToDo

Progetto universitario: sistema informativo (database relazionale + applicativo Java Swing)
per la gestione di ToDo personali, ispirato a Trello.

## Struttura

- `src/model` — package delle entity del dominio (dal diagramma delle classi):
  `Utente`, `Bacheca`, `TitoloBacheca`, `ToDo`, `StatoToDo`, `Checklist`, `Attivita`, `StatoAttivita`.
